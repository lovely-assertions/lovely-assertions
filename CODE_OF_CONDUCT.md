# Code of conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] in full.
Rather than transcribe it here, where a copy would drift from the original, the
canonical text is the one linked — please read it there.

The short version: be decent to people. Assume good faith, including from the
person whose patch you are about to criticise. Criticise the code.

## Reporting

Report unacceptable behaviour by opening a
[private report](https://github.com/lovely-assertions/lovely-assertions/security/advisories/new)
in the Security tab — it is a private channel, and it is the only one this
project runs. Reports are handled confidentially.

The maintainers are responsible for clarifying the standards and for taking
appropriate, proportionate action in response to any behaviour they judge
inappropriate, threatening, offensive, or harmful.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
